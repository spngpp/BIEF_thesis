This repository displays the code for the Quantitative Illustration chapter of the thesis. The code is composed of two Dynare scripts, each containing the model and simulations for the models developed in sections 2.2 and 2.3, and of a Matlab script used to execute the Dynare code as well as to plot the Impulse Response Functions of the simulations.
