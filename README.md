# Fiscal Policy as a Stabilization Tool: An Exploration of a Quasi-Automatic VAT Stabilizer with Endogenous Pass-Through

Author: Giuseppe Spina

Advisor: Prof. Tommaso Monacelli

Date: September 2026

# Abstract

In this thesis we investigate the effectiveness of quasi-automatic fiscal policy as a stabilization tool. Specifically, we study a rule that automatically adjusts the VAT rate in response to current output while remaining debt-neutral in the long run. We extend the framework proposed by Blanchard (2025) by allowing pass-through to emerge endogenously from firms’ decisions in a New Keynesian Model featuring nominal rigidities and external deep habits. Then, we examine the model’s responses to contractionary demand and supply shocks. The main findings are as follows. First, we confirm the results of Blanchard (2025) following a preference shock: the quasi-automatic VAT rule remains effective even when pass-through is incomplete. Second, after a productivity shock, a stronger VAT response widens the output gap in Blanchard (2025)’s benchmark but reduces it under deep habits and our policy-consistent definition of natural output. Overall, our results suggest that endogenous pass-through dynamics make such a stabilizer desirable irrespective of the relative importance of demand against supply shocks.

# Content

This repository displays the code for the Quantitative Illustration chapter of the thesis. The code is composed of three Dynare scripts, each containing the model and simulations for the models developed in sections 2.2 and 2.3 (together with its flexible price benchmark), and of a Matlab script used to execute the Dynare code as well as to plot the Impulse Response Functions of the simulations.
